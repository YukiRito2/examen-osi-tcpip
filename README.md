# Examen OSI / TCP-IP

Quiz interactivo de repaso para el modulo de Planificacio i Administracio de Xarxes (PAX), tema 1: modelo OSI y arquitectura TCP/IP.

**[Abrir el examen](https://yukirito2.github.io/examen-osi-tcpip/)**

## Que hace

- Banco de mas de 50 preguntas sobre las 7 capas OSI, el modelo TCP/IP, TCP vs UDP, handshake/ACK/ventana deslizante, cabeceras, TTL, ARP, ICMP, CRC y encapsulacion.
- Cada intento elige 15 preguntas al azar y mezcla el orden de las opciones, asi que ningun examen sale igual.
- Al terminar muestra la nota, un mensaje segun el resultado y la clave de respuestas con una explicacion breve de cada pregunta.
- Guarda el mejor puntaje en el navegador para comparar entre intentos.

## Estructura

```
index.html      estructura de la pagina
css/styles.css  estilos, temas claro/oscuro y animaciones
js/quiz.js      banco de preguntas y logica del quiz
```

Sin dependencias ni build: HTML, CSS y JS puro. Servido con GitHub Pages.
